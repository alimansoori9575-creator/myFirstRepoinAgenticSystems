1. What is the role of query parameters in this request?
Query parameters in this request are used to specify the search criteria for the GitHub API. They allow the user to filter and refine their search results based on specific keywords, programming languages, repositories, or other attributes. For example, a query parameter might be used to search for repositories that contain a certain keyword in their name or description, or to filter results by language or date of creation. This helps users find more relevant results when searching through GitHub's vast repository of code and projects.

2. Why do we use response.json() instead of response.text?
We use response.json() instead of response.text() because the GitHub API returns data in JSON format. The response.json() method parses the JSON data and converts it into a Python dictionary, making it easier to work with the data in our code. On the other hand, response.text() would return the raw JSON as a string, which would require additional steps to parse and extract the relevant information. Using response.json() simplifies the process and allows us to directly access the data we need without having to manually parse the JSON string.
